---
title: Documentation de relief
description: Carte zoomable d'un dépôt git, avec le diff superposé.
---

relief affiche un dépôt git comme une carte zoomable (système, modules, fichiers, symboles) et y superpose un diff, pour relire une PR ou comprendre un dépôt inconnu.

Commencez par [Commencer](/docs/getting-started/).
